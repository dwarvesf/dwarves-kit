# Integrations

Integrations that connect the kit to other tools. Nothing here installs itself.

- `hermes/skills/` , Hermes agent skills (`kit-board`, `kit-precedent`) that `board hermes link` installs into a Hermes profile.
- `claude-code/` , Claude Code mods that `install.sh` loads: `/board` (draws `bin/board` output in a side pane) plus four vendored mods (secrets-veil, memory-lens, loop-detective, context-inspector). Details in `claude-code/README.md`.
