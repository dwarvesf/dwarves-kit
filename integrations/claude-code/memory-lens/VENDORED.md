# Vendored

Source: github.com/yonatangross/orchestkit, `mods/memory-lens`, commit `badfc82999e424b0445ba9db6a1e9aa2aed9e20f` (the last commit that touched the folder; MIT, `LICENSE` beside this file).

Read in full before vendoring: no network, no process spawn, no file write. It reads local files only (`$.fs.list` and `$.fs.read` on the memory folders, an optional `~/.claude/memory-lens/private.json` client list and an optional mirror file written by a job outside this mod), ranks the memories against each prompt, adds the top three as one context entry for the model, and logs one line for the human.

Only runtime files are kept (manifest, `hooks/`, `src/`, `tsconfig.json`) plus the local `tests/`; the upstream README and npm tooling stay upstream. `tsconfig.json` still lists `tests/**` and `vitest.config.ts` in `include`; those paths do not exist here and tsc ignores them.
To update: re-read the diff against this commit, then copy the same files and re-apply the patches below.

Local patches:

1. `src/memory.ts` `parentProjectKey` splits on `/--(?:claude-)?worktrees-/`, so a session under `<repo>/.claude/worktrees/<name>` maps to the parent repo key as well as `.worktrees/<name>`.
2. `hooks/register.ts` also indexes the per-repo store `<cwd>/.claude/memory/*.md`, found by walking up from the session cwd with `$.fs.exists` (stops before HOME), beside the machine-local `~/.claude/projects/<key>/memory/`. `loadDocs` loops over both folders, the re-index on a Write or Edit tests both prefixes, and a file name present in both is taken from the repo store. `isIndexFile` in `src/memory.ts` now skips every `MEMORY*.md`, not only `MEMORY.md` and the archive.
3. `hooks/register.ts` sends the per-prompt transcript line to `{ to: 'debug' }`, so the recall shows in the debug log and not in every transcript.
4. `hooks/register.ts` drops the `.catch(...)` chained on `$.ui.log` in `build`: on Claude Code 2.1.292 `$.ui.log` returns void, so the chained call throws.
5. Undocumented until now, part of patch 2: two log strings changed with the per-repo store. The debug line printed after indexing is `memory-lens: indexed N memories in T ms (<dirs>)` where `<dirs>` joins the repo store and the machine-local folder with ` + `; the `/memory-lens` stats line reads `memory-lens: N memories from <dirs> · R recalled this session · query p50 .. ms p95 .. ms over N` with the same ` + ` join (or `(no project)`). Upstream named the single memory folder in each (inferred from the patch; upstream was not re-fetched).
6. The per-repo store is trusted only from an allowlisted repo (prompt injection fix). `findRepoMemory` walks up from the session cwd, takes the nearest `.claude/memory`, and stops at the git root (the first dir with a `.git` file or folder); it never reaches HOME, and refuses when HOME is unset or cwd is not under it. The store is used only when that git root is under a prefix listed in `~/.claude/memory-lens/trusted-roots` (one absolute prefix per line, `~/` for HOME, `#` comments). With no such file nothing is trusted (the kit copy ships no default roots; the earlier maintainer copy defaulted to two personal workspace folders, which the kit does not carry); a file that exists but lists nothing trusts nothing. Helpers `normalizePath`, `hasDotDot`, `defaultTrustedRoots`, `parseTrustedRoots`, `isTrustedRoot` live in `src/memory.ts`.
7. Index limits (ReDoS and cost). The `IMAGE` regex in `src/memory.ts` has a lookbehind so a match starts only at the start of a path-like run, and runs on the first 8,192 characters only (before: the whole file, quadratic: 60,000 characters took 1.5 s, 120,000 took 6 s). `loadDocs` skips a memory file over 64 KB (by the listed size, and by length after the read), and indexes at most 2,000 files. The re-index after a Write or Edit obeys the same limits.
8. The re-index check on a Write or Edit rejects a `file_path` that has a `..` segment and normalises the path before the prefix test, so `<memory dir>/../x.md` no longer counts as inside the memory folder.
9. `src/format.ts` `contextText` drops the hint "(fetch the body only if needed)" from the mirrored-memory line, and collapses all whitespace (newlines included) in the name, description, id and source; the name is capped at 90 characters. `screenLines` collapses the title the same way.
10. Kit copy only: `defaultTrustedRoots` returns no roots, so a repo's `.claude/memory` is never indexed until `~/.claude/memory-lens/trusted-roots` lists a prefix. Tests use a generic `~/workspace/acme/` root and pin the no-default behavior.
