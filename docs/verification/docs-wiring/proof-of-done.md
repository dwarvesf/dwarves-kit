## Negative control (load-bearing)

The `claim_wired()` function used by every AC2/AC3 assertion above is the SAME function applied
to a fabricated fixture doc in AC4: a claim naming a fake lib file+verb
(`kit-fixture-nonexistent-verb.sh persist`) that has zero real callers anywhere in the repo and
carries no honesty marker. The function correctly returns the SILENT ORPHAN code (1), proving the
sweep can distinguish a genuine over-claim from both a WIRED claim (return 0) and an HONEST GAP
(return 3, exercised for real on the significance-classify `record` case). Without this
distinction the sweep could not have caught the c6fbd99 bug class it exists to prevent.
