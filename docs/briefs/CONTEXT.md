# Context for implementation (SPEC-246, /kit:wrap)

## Stack
Bash entry scripts under `lib/<subsystem>/<subsystem>.sh` with a 3-line `bin/<subsystem>` forwarder; command prompts under `commands/*.md` (frontmatter `description:` + prompt body; the file IS the product). Tests are raw bash (`tests/test-*.sh`, mktemp fixtures, real git repos), discovered by `tests/run-workflow.sh` from `.github/workflows/test.yml`. Config: `kit_config_get_root <section.key> [default]` from `lib/config/kit-config.sh` for keys a project toml must never set. `docs/FEATURES.md` is generated by `bash lib/registry/feature-registry.sh generate`, never hand-edited; a new command adds a row.

## Conventions
- ADR-0034 grammar: `bin/<subsystem> <verb>`; the shim forwards, the lib entry owns the verbs. `tests/test-bin-forwarders.sh` is the census.
- Exit 64 on usage errors. STE-lite prose, no em or en dashes (a test pins this in several docs), no contractions.
- Commands open with the Self-intro banner line convention (see `commands/execute.md` first line and AGENTS.md "Self-intro").
- Consumer paths never hardcoded; default branch is detected, never assumed `main`.
- No spec or task IDs in commit subjects.

## Key files
- `bin/learn`, `lib/learn/learn.sh`: shim and verb-entry shape to copy.
